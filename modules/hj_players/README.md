HJ PLAYERS v0.3.9 (test). Обычная и расширенная настройка плашек, пропорциональный размер текста в OBS и редакторе. Разархивировать не нужно: установить ZIP через «Модули / обновления», затем перезапустить приложение.

### Сохранить настройки плашки по умолчанию
Откройте «РЕДАКТОР», выберите плашку, «Расширенная» → «Сохранить как стандарт».
Параметры сохраняются в SQLite в `settings.badge_default`. Новые игроки получают
размер, шрифт, свечение, поворот и оформление, но не позицию выбранной плашки.
«Применить ко всем в этом ракурсе» изменяет только черновик текущего ракурса;
для OBS нажмите «Опубликовать в OBS». Координаты и видимость сохраняются.

### v0.3.11 — фото игроков (тестовая версия)
В списке участников (включая дилера) нажмите 📷, выберите фото. В браузере изображение центрируется, обрезается до квадрата 512×512 и сжимается в JPEG. Сразу включается режим ФОТО.
Селектор НИК / ФОТО / ФОТО+НИК переключает режим отображения отдельно для каждого участника. Круги имеют бронзовую рамку. В OBS используйте прежний браузерный источник.
Фото сохраняются вне папки ZIP: в пользовательских данных модуля, каталог avatars. После замены ZIP фотографии сохраняются. Обычные никнеймы не изменяются.
Проверка перед эфиром: загрузить фото, переключить режимы, открыть /overlay/players, перезапустить Windows-приложение и убедиться, что фото и рассадка сохранились. При ошибке вернуться к 0.3.10.
Внимание: импорт старого JSON-конфига может сбросить поля avatar_revision/display_mode (аватары на диске останутся). Данная версия НЕ проверена на Windows и OBS.
