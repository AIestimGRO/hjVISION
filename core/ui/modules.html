Модули и обновления

Отдельные блоки, совместимые с CORE API 1.x. Данные и рассадка сохраняются вне папок модулей.

Обновляйте модули только между трансляциями. Если OBS-оверлей подключён, установка и откат заблокированы. Устанавливайте только ZIP из доверенного источника: Python-модули являются исполняемым кодом.

Установить обновление модуля

Выберите ZIP одной папки hj_players/ или другого модуля, созданный через упаковщик и содержащий checksums.json. Сначала проверьте пакет.

После установки / отката перезапустите HI, JACK LIVE для загрузки новой версии. Восстановление предыдущего модуля не удаляет пользовательские данные.
