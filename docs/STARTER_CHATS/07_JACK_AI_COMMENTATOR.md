Вноси код только в указанную область. Если требуется изменение общего API/другого модуля, подготовь отдельный контракт и согласуй его в центральном чате, прежде чем менять. ## Задачи этого модуля

Реализовать ИИ-комментатора с режимом предпросмотра и отдельно управляемой озвучкой в OBS. Контекст только из подтверждённых событий и локальных профилей; API-ключ только локально. Отдельный **JACK AI TRAINING SYNC**: ChatGPT (текст или голос) → предложение изменений → явное подтверждение пользователя → публикация в ОТДЕЛЬНОМ GitHub репозитории AIestimGRO/hi-jack-ai-training (имя согласовано, существование нужно проверить) → кнопка 'ОБНОВИТЬ ПРАВИЛА ИЗ GITHUB' в основном приложении → проверка manifest, подписанного источника/коммита и контрольных сумм, совместимости, тестов → атомарное применение только к новым комментариям → локальный откат. Декларативные JSON/YAML: характер, стиль, частота, удачные/нежелательные примеры, юмор, анализ покерных ситуаций, тестовые сценарии; не запускать скачанный код. Минимальные GitHub-права read для клиента, Windows Credential Manager/DPAPI для ключей. Недоступность GitHub/интернета не отключает ранее проверенные правила; обновление не прерывает текущую реплику и эфир. Ни в один репозиторий не класть историю раздач или ключи.

## Приёмка

Голосовая поправка в ChatGPT, явное утверждение, независимый выпуск правил, обнаружение/загрузка без EXE, новые реплики по новым правилам, откат, offline, безопасные и проверяемые сценарии, отсутствие передачи ключей.
