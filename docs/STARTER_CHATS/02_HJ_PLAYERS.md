## Задачи этого модуля

Развивать эфирный редактор 16:9 (1920×1080 — система координат, а не размер окна). Реальный кадр камеры, боксы, дилер, 10 игроков, автоматическая начальная позиция + независимое ручное перетаскивание; публикация в OBS только по подтверждению. Обычные настройки — позиция, размер и поворот -90/0/+90 с авто-масштабированием ника; расширенные сохраняются. Стандарт из выбранной плашки, применение ко всем без изменения координат. Номера BOX не выводить зрителям. Устранить UX-недочёты, поддержать отдельные раскладки по ракурсам, undo, сетку, направляющие, замену игрока, статусы, скрытие; не менять данные без миграции.

## Приёмка

Установка через ZIP поверх 0.3.10, 10 игроков и 10 боксов, размеры и поворот, сохранение дефолтов, независимое редактирование профилей, публикация точно совпадает с OBS, откат сохраняет рассадку.
