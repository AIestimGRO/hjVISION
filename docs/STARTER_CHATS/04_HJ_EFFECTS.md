## Задачи этого модуля

Довести BRONZE PREMIUM по утверждённым референсам и пять сменных тем; единый визуальный язык тёмная эмаль/бронза/медь, чёткий объёмный текст, аккуратное свечение. Эффекты ALL-IN, DOUBLE UP, BOUNTY, WINNER, PLAYER OUT, BREAK, FINAL TABLE, JACKPOT со звуком, безопасным stop/restart и разумной длительностью. Масштаб 1920×1080, прозрачность для OBS, эффект не должен перекрывать критичные данные без согласия оператора. Только собственные или разрешённые аудиоресурсы. События и параметры из CORE API, не делать прямых несанкционированных изменений игроков.

## Приёмка

Эффекты запускаются и останавливаются без зависания OBS, не ломают плашки, рендер качественный, звук регулируется, событие ошибочного запуска можно остановить, модуль устанавливается ZIP отдельно.
