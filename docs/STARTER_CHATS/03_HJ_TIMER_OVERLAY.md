## Задачи этого модуля

Источник данных только read-only: https://timer.hijackpoker.ru/api/state. Блайнды SB/BB, анте, номер раунда, оставшееся время, следующий раунд, пауза и перерыв. Управлять оформлением ТОЛЬКО из основного окна HI, JACK LIVE — отдельная /timer-control не должна быть обязательной. Чёткая графика HTML/SVG/CSS без растяжения: compact/broadcast/premium, бронзовое оформление, настройка размера и прозрачности, положение на общем кадре 16:9 и отдельные ракурсы. Точность синхронизации с server_time, без отрицательного отсчёта; gracefully degrade при недоступности сети (показывать состояние/последние валидные данные, не придумывать блайнды). Сохранение и публикация позиции раздельно от HJ PLAYERS.

## Приёмка

Пауза, продолжение, смена уровня, перерыв и сеть offline; показатели равны API; OBS-оверлей прозрачен 1920×1080, лёгкий для CPU; настройки из основного окна; при обновлении других модулей таймер работает.
