## Задачи этого модуля

Разработать независимый адаптер obs-websocket: авторизация локально, определение текущей сцены, список источников, состояние подключения, измерение задержек, ручное и затем опциональное автоматическое переключение профилей HJ PLAYERS и HJ TIMER по активной камере. Запрос кадра/скриншота из OBS для редактора, видимость браузерных источников и восстановление после потери связи. Не перехватывать захват, микширование и трансляцию: OBS остаётся главным приложением. При недоступном OBS другие функции HI, JACK LIVE остаются работоспособными.

## Приёмка

Включённая/выключенная студия OBS, смена камеры, потеря и восстановление websocket, корректная сцена/ракурс, никакой принудительной остановки записи или эфира.

1. Проверь репозиторий и фактическую версию модуля в `module.json`, сопоставь с контрольным снимком, проверь ограничения и работу текущих API.

4. После тестов пользователя подготовь краткий интеграционный отчёт для центрального чата.
