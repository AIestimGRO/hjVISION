# JACK AI TRAINING SYNC — специализированный чат внутри hj_ai_commentator

Это **не** новый модуль CORE: реализация в `modules/hj_ai_commentator/`, обучающие данные в отдельном репозитории `AIestimGRO/hi-jack-ai-training` (перед началом проверить, что он существует; создать при подтверждении владельца).

## Задача

Голосовое или текстовое обучение через проект ChatGPT → сформировать diff декларативных правил → явное подтверждение пользователем → публикация утверждённой версии в GitHub → `JACK AI → Обучение → ОБНОВИТЬ ПРАВИЛА ИЗ GITHUB` → проверка источника, целостности, совместимости, тестов → резервная копия → атомарное переключение только для **новых** комментариев. Показать версию, дату, changelog, наличие обновления, `ОТКАТИТЬ ПРАВИЛА`, `ПРОВЕРИТЬ ДЖЕКА`. Offline — оставить последнюю локально проверенную версию.

## Разделение и безопасность

Репозиторий содержит character/personality, style, cadence, humor, poker-analysis, хорошие/нежелательные примеры, тестовые сценарии и manifest с версиями и SHA-256. Не хранить реальную историю раздач, игроков и ключи. Ключи в Windows Credential Manager/DPAPI. GitHub read-only для Windows приложения; запись правил только через подтверждённую ChatGPT-GitHub операцию. Загруженные JSON/YAML — данные, не исполняемый код.

## Приёмка

Оформить тесты: подтверждение, отклонение, несовместимая версия, повреждение файла, недоступный GitHub, гонка обновления/запущенного комментария, откат, отсутствие перезапуска EXE и влияния на соседние модули. Изменения в `main` — только после физического тестирования и явного разрешения пользователя.
