HI, JACK LIVE — 11 ноября 2026
ТЕСТОВОЕ обновление для Windows 11; не подтверждено физическим тестом.

Состав:
1. HJ PLAYERS v0.3.8 — номера BOX 1/BOX 2/... не показываются на плашках, но остаются в управлении. Редактор 16:9 вписан в окно, широкий режим вручную.
2. HJ TIMER OVERLAY v0.2.0 — компактная графика высокого разрешения, управление и перетаскивание таймера в главном окне /admin. URL OBS прежний.

УСТАНОВКА:
- В OBS скройте браузерные источники HI, JACK LIVE с включённым «Отключать источник, когда он не виден» или закройте OBS. Количество подключённых оверлеев должно быть 0.
- Откройте HI, JACK LIVE → Модули / обновления, установите по очереди 2 ZIP, не распаковывая: HJ PLAYERS 0.3.8, затем HJ TIMER OVERLAY 0.2.0.
- Полностью завершите программу штатной кнопкой «Завершить программу», затем запустите снова; если повторный запуск блокирует порт 8765 — завершите оставшиеся HiJackLive.exe в Диспетчере задач.
- Откройте главное окно, выберите «Редактор» и настройте таймер прямо рядом с игроками. Нажмите «Опубликовать таймер» отдельно от публикации раскладки игроков.
- Для OBS: отдельный браузерный источник таймера http://127.0.0.1:8765/overlay/timer?layout=top, размеры 1920x1080; он должен быть над камерой. Для side смените layout=side.
- Управление реальным временем турнира (старт/пауза) пока остаётся на timer.hijackpoker.ru. Здесь редактируется только графический оверлей.

ОТКАТ:
Модули / обновления → выбрать нужный модуль → откатиться к последней резервной версии → перезапуск.
Данные игроков и позиций хранятся отдельно и не удаляются при обновлении исходников модулей.

Важное ограничение: автоматическая проверка ≠ тест на вашем Windows/OBS. Не публикуйте как стабильную до проверки.
