HI, JACK LIVE v0.3.4 - совместимый запуск на Windows 11

Сборка: распакуй весь архив в новую папку, нажми BUILD_EXE_WINDOWS11.cmd.
Запуск: после BUILD SUCCESS открой dist\HI_JACK_LIVE\HiJackLive.exe.

Управление откроется в отдельном окне Microsoft Edge без обычных вкладок.
Это полноценный установленный Edge, а не встроенный компонент WebView2.
Локальный сервер и все ссылки для OBS останутся на http://127.0.0.1:8765.

Как проверить причину старого зависания:
1. Закрой предыдущие процессы HiJackLive.exe через Диспетчер задач.
2. Сначала запусти START_BROWSER_DIAGNOSTIC.cmd из новой папки dist\HI_JACK_LIVE.
3. Проверь переключение ЭФИР/РЕДАКТОР, открытие окна игрока, сохранение.
4. Если обычный браузер работает, а START_WEBVIEW2_TEST.cmd зависает,
   проблема практически локализована в старом GUI/WebView2-слое.
5. Журналы: OPEN_DIAGNOSTICS.cmd, файл launcher.log.

Закрытие отдельного окна Edge --app останавливает локальный OBS-сервер.
Перед эфиром проверь всё на своём ПК. Windows GUI тут не запускался.
Не удаляй %LOCALAPPDATA%\HiJackLive и не перезаписывай старую сборку.
